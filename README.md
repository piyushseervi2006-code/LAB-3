# Book Information Website

## Aim
Design a website for book information using HTML frames.

## Description
This website displays a list of books on the left side and the
information of the selected book on the right side.

## Books Included
- Alice in Wonderland
- The Little Prince

## Technologies Used
- HTML
- CSS
- HTML Frames

## Files
- index.html - Main page containing the frames
- books.html - Contains the list of books
- welcome.html - Welcome page
- alice.html - Alice in Wonderland information
- littleprince.html - The Little Prince information

## How It Works
The left frame contains the book list. When a book is clicked,
its information is displayed in the right frame.

## How to Run
Open `index.html` in a web browser.

## Conclusion
This project demonstrates the use of HTML frames, links and
multiple web pages to create a simple book information website.
